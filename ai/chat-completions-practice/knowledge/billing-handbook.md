# 客服与计费手册（长文示例）

产品名：Crystal Notes（虚构练手知识库）。本文故意写长，用于演示「整篇一个向量」和「切成多块再检索」的差别。

## 计费套餐

免费版每月可创建 50 条闪记，合集上限 3 个。超出后闪记会进入只读，不能新建，但已有内容仍可导出。

专业版月费 29 元，闪记不限量，合集上限 100 个，并开放 API Key（仅管理员角色可创建 Key）。年付折扣为九折，按自然年计算，中途升级按剩余天数折算。

团队版按席位计费，每位 39 元/月，最少购买 5 席。团队版包含共享合集与审计日志；审计日志默认保留 90 天。

## 发票与退款

个人用户可申请电子普通发票，抬头需与支付账号实名一致。企业用户可申请增值税专用发票，需提供税号与开户行信息，提交后 5 个工作日内开具。

订阅后 7 天内未使用过 API Key、且闪记创建少于 10 条，可申请全额退款。超过 7 天或已大量使用，只退剩余整月费用，不退当月已用部分。

退款申请入口在「设置 → 账单 → 申请退款」。到账时间因支付渠道而异，银行卡通常 3～10 个工作日。

## 数据导出与注销

用户可随时导出自己的闪记为 Markdown ZIP。导出任务在后台排队，完成后站内信通知下载链接，链接 24 小时有效。

申请注销账号后进入 15 天冷静期：期间可登录撤销注销。冷静期结束前，数据仍可导出；结束后不可恢复，合集与 API Key 一并作废。

团队版主管理员注销前，必须先转移所有权或解散团队，否则注销申请会被拒绝。

## 服务等级与补偿

专业版与团队版承诺月可用率 99.5%。若当月低于该值，可按差值为当月账单抵扣（例如可用率 99.0%，差值 0.5%，抵扣当月费用的 0.5%）。

计划内维护会提前 48 小时在状态页公告，不计入可用率统计。不可抗力与用户侧网络问题不在补偿范围。

状态页地址：`status.crystal-notes.example`（虚构）。

## 常见拒答场景

客服话术：涉及其他用户的私有闪记内容、未公开的水晶分明细算法、以及未发布的路线图日期，一律不得透露。可引导用户查看公开文档或提交工单。

工单优先级：支付/无法登录为 P1（4 小时内响应）；导出失败为 P2（1 个工作日）；功能建议为 P3。
